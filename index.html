Bilingual EPUB Maker

Turn an AO3 HTML download into an EPUB where every paragraph is translated followed by its original. Everything runs in your browser using Chrome's built-in translator: nothing is uploaded, and no account or key is needed.

This browser doesn't have Chrome's Translator API. Use desktop Chrome 138 or newer. You can still load a file and look around, but translating is disabled.

1. Choose the AO3 file

2. Choose chapters and language

    3. Translate and build

    Download EPUB

    Finished paragraphs are stored in this browser (a few MB per book) so re-running does not repeat work. Clear them to free the storage or to start fresh.

    Machine translation is imperfect. The original text is always kept next to it.
